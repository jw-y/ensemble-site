Use your usual Codex chats in Ensemble

  • New ChatGPT profiles use the default Codex home (~/.codex), sharing its login and chat history with your usual Codex setup.
  • Turn off “Use default Codex home” in the profile editor for a separate account and chat history.
  • Existing profiles keep their original storage setting. Changing it takes effect after quitting and reopening that profile; existing chats remain in their original folder.
  • Deleting an Ensemble profile preserves the default Codex home and its chats.
